## Reduce Obsidian marketplace review warnings

tool: codex

- Released 1.0.6 compatibility fixes for Obsidian marketplace automated review warnings.
- Replaced production `globalThis` request-url wiring with an explicit Obsidian request-url registry.
- Replaced direct `document` event wiring in runtime UI components with `activeDocument` for popout compatibility.
- Replaced `Vault.delete` with `FileManager.trashFile` for regenerated managed image cleanup.
- Removed shell-based Mermaid rendering from the plugin runtime; Mermaid blocks remain as code blocks in the plugin preview.
- Changed the plugin manifest description to English for marketplace listing compatibility.
- Verified with `npm run typecheck`, `npm run test`, and `npm run obsidian:dev`.
